# הרצת המשחק

1. פתח טרמינל בתיקיית הפרויקט.
2. הרץ שרת מקומי: `python3 -m http.server 8080`
3. פתח כרום בכתובת `http://localhost:8080`
4. הרחב למסך מלא (F11).

להרצת הבדיקות: `node --test`

# קיצורי דרך למנחה (נסתרים מהמשתתפים)

המשחק שומר את ההתקדמות ב-`localStorage`, כך שמשחק ניסיון לפני האירוע יישאר על המסך.
לפני שהקבוצה מתחילה — אפסו את המשחק.

| קיצור | פעולה |
| --- | --- |
| `Ctrl+Shift+R` | איפוס מלא: מוחק את כל ההתקדמות (חידות שנפתרו, אותיות שנאספו, מיקום המפה) ומרענן את הדף. תופיע הודעת אישור לפני המחיקה. |
| `Ctrl+Shift+S` | מסמן את החידה שמוצגת כרגע כפתורה וחוזר למפה — מוצא חירום אם הקבוצה נתקעה. אם המסך הנוכחי אינו מסך חידה (למשל המפה), לא קורה כלום. |

איפוס ידני (אם הקיצור לא עובד): פתחו את קונסולת הדפדפן (F12), הריצו `localStorage.clear()` ורעננו את הדף.
